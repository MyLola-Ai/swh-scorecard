What "approve" does
Clicking Approve creates a Firebase Auth user with their email, sets their plan, and emails them a "set password & sign in" link. They can sign in via the iOS app's paywall ("Already a member?") or at app.stopwastinghandshakes.com. TestFlight invites are separate — invite them in App Store Connect manually after approving.

How rollouts work
Edits below update the global catalog at platform/activities. Point/icon/lead changes propagate automatically — both apps merge global values on top of each user's list at load time. Use Force-sync to all users only when you've added a new activity and want existing users to see it; this is purely additive and never overwrites or removes activities a user has added or edited themselves.
